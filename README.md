# UnderAcademy College

Home of the *Journal of Untrained Models*, published by UnderAcademy College, an unaccredited anti-degree institution founded by Talan Memmott in 2011.

## Layout

```
index.html                          front page
journal/
  vol5-monetized-number/index.html  The Monetized Number
```

Each issue lives in its own folder under `journal/`. To add one, make a new folder with an `index.html` and link it from the front page.

## Notes

- Issues save each reader's reload progress in their own browser. Moving the site to a new address starts readers fresh.
- *The Monetized Number* still links to two pieces hosted on claude.ai (the Agentic Dissertation Defense and *The Self-Improving Number*). They will move here as their own folders.
